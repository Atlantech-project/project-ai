# Contract change log

Proposed changes to the team contracts in `docs/tasks/ATLANTECH_Contracts.md` (`CT-01`–`CT-26`). That file stays the authoritative text; this log records proposals until the contract's Owner and Reviewers decide.

- Entries are numbered `CL-001`, `CL-002`, … and name the `CT-` (and any `DEC-`) IDs they relate to. Don't create a new `CT-` ID here.
- Every entry starts as `PROPOSED`. It becomes `APPROVED` only when the contract's Owner and Reviewers have explicitly approved it, and the entry records who approved it and when.
- Each entry cites the evidence it rests on.

Entry template:

```
### CL-<nnn> · <title>
| Field | Value |
|---|---|
| Status | PROPOSED |
| Related | <task-id>, <CT-/DEC- IDs> |
| Owner | <team> |
| Reviewers | <teams> |
| Proposed by / date | <name>, <YYYY-MM-DD> |
| Evidence | <documents, files or tests> |
| Change | <what changes, with the contract version bump> |
| Reason | <why the current text is not enough> |
| Impact | <tasks, tables, teams affected> |
```
