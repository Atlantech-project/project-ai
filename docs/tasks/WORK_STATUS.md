# Work status

One row per task that has been started. The official task list stays `docs/tasks/ATLANTECH_AI_TASKS.md`; this index doesn't copy it, and tasks that haven't started don't appear here. Each row links to the task's status record in `docs/tasks/status/<TASK-ID>.md`, which holds the detail (plan and approval, verification, review findings, blockers).

Status values follow the backlog (§1.3): `NOT STARTED`, `IN PROGRESS`, `IN REVIEW`, `DONE`, `BLOCKED (<item>)`, `DEFERRED (<decision>)`. A task is `DONE` only after its pull request is reviewed and merged.
