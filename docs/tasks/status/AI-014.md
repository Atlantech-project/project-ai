## Summary of the change
- **`common/units.py`:**
  - The `Unit` enum holds every `SpeedUnit`, `VisibilityUnit` and `ConstraintUnit` value.
  - `parse_unit` matches exactly and raises `UnknownUnitError` otherwise.
  - `convert` works within one dimension only, using exact definitions (1 NM = 1852 m, 1 kn = 1852 m/h). A cross-dimension conversion raises `IncompatibleUnitsError`.
- **`common/time.py`:**
  - `load_zone` uses `zoneinfo` only and raises `UnknownTimeZoneError` for an unknown name.
  - `to_local` accepts aware UTC only.
  - `to_utc` takes a naive local time and raises `NonExistentLocalTimeError` in a gap and `AmbiguousLocalTimeError` in an overlap, both under `LocalTimeError`.
  - `shift_interval_utc` treats `end < start` as the next local day and raises when `end == start`.
- **`common/datum.py`:** `check_datum_consistency` raises `MissingDatumError` or `DatumMismatchError`, both under `DatumError`. It compares exactly and does no conversion (DEC-27).
- **`common/__init__.py`, `tests/unit/common/`** (`__init__.py`, `test_units.py`, `test_time.py`, `test_datum.py`).
- **`pyproject.toml`:**
  - runtime dependency `tzdata>=2026.6`, unconditional;
  - `common` added to mypy `files` and to coverage `source`.
- **`uv.lock`:** only the `tzdata` additions (13 lines).
  - `uv add` with the local uv 0.10.6 had rewritten `revision = 5` to `3`. It was set back to `5`.
  - `uv lock --check` then passed with both uv 0.10.6 (local) and uv 0.13.6 (CI's `UV_VERSION`, run through `uvx --from uv==0.13.6`).
