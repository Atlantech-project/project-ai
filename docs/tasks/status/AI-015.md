## Deviations from the plan
- `.gitattributes` gets `tests/fixtures/*.json -text`, because `core.autocrlf` is true here and a CRLF checkout would break the byte comparison. Not in the plan's file list.
- Integration fixture uses the shared `port_db` (see above), not a database per test.
- Minimum scale draws container vessels only (it has no non-container terminal); the plan's weights apply where a non-container terminal exists. Written into the assumptions.
- IMO numbers carry a deliberately wrong check digit so none can be a real ship (an addition to the plan, in the assumptions).
- `DEC-`/`CT-` IDs: none assigned or changed.
